# Infinite World RPG

Модульная одиночная RPG на Godot 4 с процедурным миром и браузерной целью.

## Реализованный игровой срез
- Трёхпанельный интерфейс: меню героя, интерактивная карта, журнал.
- Детерминированная генерация чанков по seed и координатам, включая отрицательные.
- Биомы, процедурные POI и контекстные действия.
- Перемещение по соседним чанкам, туман войны, панорамирование и масштабирование карты.
- Разведка, обход, пошаговый бой, тайники, святилища и торговля.
- Добыча, инвентарь, зелья, опыт, бесконечная кривая уровней и квест первой охоты.
- Локальное сохранение с резервной копией и проверкой версии.
- Headless smoke test для генерации, каталогов, инвентаря, экипировки, способностей, боя, фильтрации некорректных предметов и round-trip сохранения.
- GitHub Actions workflow для импорта проекта Godot и запуска smoke test на каждом push в main.
- Каталоги биомов, POI, предметов и стартовых квестов хранятся отдельно в data/.

## Запуск
1. Установите Godot 4.2 или новее.
2. Откройте папку проекта через project.godot.
3. Запустите F5 или экспортируйте Web.

## Проверка
Из корня проекта выполните:
    godot --headless --path . -s res://tests/smoke_test.gd

## Web
Рендерер настроен на Compatibility (GL Compatibility). Установите экспортные шаблоны той же версии Godot, добавьте preset Web в Project → Export и экспортируйте в export/web. Публикуйте статические файлы по HTTPS с корректным MIME type для wasm.

## Ограничения
Это рабочая вертикальная основа, но не завершённый релиз мастер-промта. Не реализованы глубокие диалоги, полноценные деревья навыков, развитая симуляция фракций, сезоны, звук, локализация и полный каталог контента. Эти системы остаются следующими крупными направлениями.
